## Featured project: ClaimFlow

ClaimFlow is a self-directed portfolio project for managing employee expense claims from submission to reimbursement. Employees submit claims with receipts, managers review them, and finance administrators maintain policy and mark approved claims as paid.

- **Frontend:** React 19 and TypeScript (Vite), with sign-in through Amazon Cognito
- **Backend:** TypeScript on AWS Lambda and API Gateway, with DynamoDB and S3
- **Infrastructure:** AWS CDK, deployed manually to `ap-southeast-1`
- **Testing:** Vitest and React Testing Library, with GitHub Actions checks

**Links**

- Source code: [github.com/Hollowpath/claimflow](https://github.com/Hollowpath/claimflow)
- Live site: [d3vq4pyeoivioy.cloudfront.net](https://d3vq4pyeoivioy.cloudfront.net)

Accounts on the live site are created by an administrator, so it isn't open to self-registration. To try the application without an account, the repository includes local demo instructions that run it on your machine with sample users and no AWS account.

ClaimFlow is a portfolio project, not a production system. The repository's collaboration playbook describes how AI-assisted development was used and reviewed.
